# `tests/fixtures/nasty/bertandatangan-asli.pdf` — a REAL cryptographic signature

Not generated by a script in this repo, and that is the point. `bermeterai.pdf`
is hand-shaped by `gen-fixture-bermeterai.mjs`: we wrote the signature
dictionary ourselves, so it can only prove the detector reads bytes we already
knew how to write. This file was produced by an outside signing pipeline that
knows nothing about pdflokal, so it is evidence rather than a mirror.

**Source document:** `tests/fixtures/nasty/surat-word.pdf`, unmodified. That is
deliberate — the unsigned original stays in the corpus, so the pair is a
CONTROL: the same document reads `false` before signing and `true` after, and
the only difference is the signature. Two unrelated files could never show that.

**Made with** pyHanko (Python) and a throwaway self-signed certificate:

```
openssl req -x509 -newkey rsa:2048 -keyout k.pem -out c.pem -days 365 -nodes \
  -subj "/CN=Fixture Signer/O=pdflokal test/C=ID"
openssl pkcs12 -export -out signer.p12 -inkey k.pem -in c.pem -passout pass:test
# then pyhanko: append_signature_field(field_name='Sig1') + sign_pdf
```

**Verified by a DIFFERENT PROCESS**, not by us — poppler's `pdfsig`, which
shares no code with this repo:

```
Signature Type: adbe.pkcs7.detached
Signing Hash Algorithm: SHA-256
Signed Ranges: [0 - 33986], [38856 - 39373]
Total document signed
Signature Validation: Signature is Valid.
Certificate Validation: Certificate issuer isn't Trusted.
```

The untrusted issuer is expected and irrelevant: the certificate is self-signed.
The SIGNATURE is cryptographically valid, which is the property the detector
cares about — `/ByteRange` written in the clear by a real signer.

## ⚠️ What this still does NOT prove

It is not a Peruri e-meterai. It proves the detector reads genuine PAdES output
from a signer that has never heard of us; it does not prove Peruri's specific
output shape. **That residual is why the seal note is a warning and not the
protection.** `passThroughSource` in `js/core/export.js` never consults
`signed` — an untouched document is handed back verbatim whether or not we
recognised a signature — so a detector miss costs the user the WARNING, never
the seal.
