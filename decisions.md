
## 2026-07-28 — ⚖ RULED: ship the `residual` SIGNAL now, HOLD the cover change (PM call)
- **The bench found where the lie is born** — `text-walk.js:260-265`. A record can pass BOTH positional tests (`perp`, `alongOk`) and fail only `sizeOk`, and is then **silently dropped**. `matched` goes true off whatever else did match. **The planner knows it declined a glyph run sitting inside the span it was told to clear, and throws that knowledge away.** The dash leader was just the first document to expose it. Fix: count positionally-inside records matched by NO target, expose as `residual`, and let `reason` become `clean` / `residual` / `no-match`.
- ✅ **Telemetry half: BUILD NOW.** Including the new `'residual'` enum value rather than folding into `'untrustworthy-run'` (which means the `badBts` decline — genuinely different). **The bench's reasoning is exactly right and is the day's lesson applied: folding a new signal into an existing bucket is precisely how `weightRatio 1.28999` got eaten this morning.** The tripwire at `page-surgery-dashleader.test.mjs:230` gets RE-PINNED to `'residual'` — it stops documenting a lie and starts asserting the instrument tells the truth about a cut it didn't make.
- ⏸ **Cover half (`residual > 0` ⇒ keep the whiteout): HELD.** Three reasons, in order of weight:
  1. **The destroy-vs-preserve asymmetry, which is decisive.** An orphan glyph beside replaced text fails **loudly** — the user sees something is wrong and can act. A whiteout over a footnote marker, superscript, or small-caps fragment fails **silently** — content they never asked to remove is gone, and the page looks correct. **This project's entire defect history is "looks correct but isn't." We do not add a silent-loss path to fix a loud one.**
  2. **Zero data.** Post-`39e0b9f` per-run targets, the bench's own read is that residual is now *unlikely* — but unlikely is a hypothesis, and we are about to have an instrument that measures it. Changing visible output on real users' documents ahead of the data is exactly what the founder's telemetry-first discipline exists to prevent. **Ship the instrument, read the rail, then decide.**
  3. It changes what a user's document looks like, so the decision is his, not the PM's — and he should get it with a frequency number attached, not as a hypothetical.
- **THE THIRD OPTION, which is probably where this lands and neither of us named at first: if `residual > 0`, DECLINE THE EDIT.** Don't cut, don't stamp, don't cover — keep the document exactly as it was and tell the user we can't edit this line safely. That is the pattern this product already uses everywhere else (the font ladder declines rather than guessing; `buildEditedPageBytes` already has a declined-edit path that keeps the edit as a DOM overlay instead of baking it). It preserves the document, fails loudly, and needs no guess about which of two bad renders is less bad. **Blocked on: frequency data from the new signal, and his copy for the notice (client-facing words).** Design toward it; do not build it yet.
- **Honest limit going in the module header either way** (bench's own flag, correct): this cannot see a residual op positionally OUTSIDE the target span. Per-run targets make that unlikely, not impossible — write the blind spot down so the new enum doesn't imply completeness.

## 2026-07-28 — THE GATE'S OWN BLIND SPOT: endpoints see NET change, not movement (bench finding — bank this)
- `npm run gate` / `scripts/qa-gate.mjs` landed (`164153b`, local). PM verified independently: `gate:self-test` passes, the 4s sampler is real (`setInterval` at line 228), VOID is checked FIRST and beats both GREEN and RED, exit 90.
- **The finding worth keeping forever.** The bench's FIRST draft fingerprinted before and after. They then asked what it would look like if it were blind — and built the case: a probe file created at t+40s and deleted at t+55s. **All 266 tests passed, and the start and end digests were IDENTICAL (`afe2fa9b…` at both ends, same HEAD).** A before/after guard would have certified GREEN over a tree that demonstrably moved, because **endpoints measure NET change; a file that appears and disappears is served to every test in between and leaves no trace at either end.** Only the mid-run sampler saw it.
- **They also falsified the self-test itself** — a copy with the content-hashing line removed correctly reports *"an edited file produced the SAME digest — the guard is blind."* A test that cannot fail proves nothing, including a test of a guard.
- **Generalizes past this repo:** any before/after comparison — a checksum, a DB snapshot, a config diff, a "nothing changed" assertion — measures net difference and is blind to transient state that was live for the whole window it was supposed to protect. **If what you care about is "did this stay still", sample it; don't difference its endpoints.** Kin: [[plausible-answer-from-unchecked-data]] — the endpoints returned a confident, plausible, verified-looking answer derived from a window they never actually observed.
