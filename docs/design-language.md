# Design language + interaction model (founder taste — LAW for any UI work)

*Moved out of `app/CLAUDE.md` 2026-07-30 (progressive-disclosure ruling: what cannot be pruned is moved). Read this BEFORE any UI, design, or copy work in this repo, together with the design skills in `.agents/skills/`.*

## Design language

Red `#dc2626` on warm stone · Plus Jakarta Sans · red chrome never prints · paper-on-desk shadows ·
stempel-press buttons · the 5-stamp language ("cap = pernyataan status", never decoration).
**Never default signature ink to a colour** — user content renders as the user made it. Design skills
are installed in `.agents/skills/`; load them before any UI work.

**Interaction model, both founder-ratified:** camera-first touch (selection commits at release);
select-then-edit for text (first click/tap selects, the next one edits — no double-tap timing windows).
