Kebijakan Privasi

PDFLokal dibangun dengan satu prinsip utama: privasi kamu adalah prioritas. Semua proses edit PDF dan gambar berjalan 100% di browser kamu. Tidak ada file yang diupload ke server manapun.

Prinsip Utama Kami

  • 100% Client-Side Processing, Semua proses berjalan di browser kamu, bukan di server kami
  • Tidak Ada Upload, File PDF dan gambar kamu tidak pernah dikirim ke server manapun
  • Tidak Ada Penyimpanan, Kami tidak menyimpan file kamu di manapun, setelah tab ditutup file hilang
  • Open Source, Kode sumber terbuka, siapa saja bisa verifikasi klaim privasi kami

Cara mudah membuktikan: Coba matikan koneksi internet kamu, lalu gunakan PDFLokal. Semua fitur tetap berjalan normal karena tidak ada data yang dikirim ke server.

Data yang TIDAK Kami Kumpulkan

  • File PDF atau gambar yang kamu proses
  • Isi dokumen, teks, atau tanda tangan
  • Informasi pribadi (nama, email, dll)
  • Data lokasi atau GPS
  • Riwayat penggunaan atau aktivitas

Tentang Analytics

Kami menggunakan Vercel Web Analytics untuk memahami berapa banyak orang yang menggunakan PDFLokal. Analytics ini bersifat:

  • Anonim, Tidak ada data pribadi yang dikumpulkan
  • Agregat, Hanya statistik umum seperti jumlah kunjungan
  • Tanpa Cookie Tracking, Tidak menggunakan cookie untuk melacak kamu
  • Privacy-Focused, Tidak dijual ke pihak ketiga

Telemetri Produk

Selain analytics kunjungan di atas, PDFLokal juga mengirim data teknis kecil ke server kami sendiri (bukan pihak ketiga) tentang bagaimana fitur-fitur dipakai, supaya kami tahu alat mana yang berguna dan mana yang perlu diperbaiki. Datanya sengaja dibuat sesempit mungkin:

  • Alat mana yang kamu pakai (Teks, Tip-Ex, Tanda Tangan, dll) dan berapa lama sebuah proses berjalan
  • Apakah sebuah font di dokumen berhasil dikenali atau tidak
  • Jenis perangkat secara umum (HP / tablet / desktop) dan jumlah halaman dalam rentang (1, 2-5, 6-20, 21+)

Yang TIDAK pernah kami kirim: isi dokumen, teks yang kamu tulis atau edit, nama file, gambar, atau nama font asli. Prinsip "filenya tidak pernah diunggah" tetap 100% berlaku, telemetri ini cuma menghitung APA yang sebuah fitur lakukan, bukan APA isi dokumenmu.

Nggak ada cookie, nggak ada ID yang mengikuti kamu antar kunjungan, setiap sesi cuma dapat ID acak yang hilang begitu tab ditutup. Datanya kami simpan sendiri di infrastruktur kami sendiri, nggak dijual atau dibagikan ke siapa pun, justru ini lebih privat dibanding Google Analytics yang dipakai kebanyakan situs lain, karena datanya nggak pernah keluar dari server kami.

Khusus fitur Edit (masih beta): kalau kamu kasih rating 👎, kami akan tanya dulu, "Boleh kami minta dua potongan ini?", sebelum apa pun terkirim. Ini nggak otomatis sama sekali: cuma jalan kalau kamu sendiri yang tap "Kirim". Yang kami minta juga cuma satu baris teks yang barusan kamu edit, dipotong jadi dua gambar kecil (sebelum dan sesudah diedit), dan kamu LIHAT SENDIRI dulu kedua potongan itu di layar, persis apa adanya, sebelum ada tombol "Kirim" buat ngirimnya. Kalau kamu pilih "Nggak usah" (atau nggak pilih apa-apa), potongan itu nggak pernah keluar dari perangkatmu, rating dan catatanmu (kalau ada) tetap terkirim seperti biasa, cuma tanpa gambar. Prinsip "filenya tidak pernah diunggah" tetap 100% berlaku di sini juga: yang mungkin terkirim cuma potongan satu baris yang KAMU pilih untuk dikirim, bukan halaman, bukan dokumen, dan tentu bukan file kamu.

Penyimpanan Lokal (Local Storage)

PDFLokal menyimpan beberapa preferensi di browser kamu menggunakan Local Storage. Data ini hanya tersimpan di perangkat kamu dan tidak pernah dikirim ke server.

Key Fungsi
pdflokal_theme Menyimpan preferensi tema (light/dark)
pdflokal_changelog_last_closed Mengingat changelog terakhir yang sudah dibaca
pdflokal_signature Menyimpan tanda tangan di perangkat ini agar tidak perlu digambar ulang
pdflokal_signature_hint_shown Mengingat bahwa petunjuk tanda tangan sudah pernah ditampilkan
pdflokal-ps-voted Mengingat bahwa ajakan uji coba Play Store sudah dijawab
pdflokal-ps-last Menyimpan kapan ajakan uji coba Play Store terakhir ditampilkan
pdflokal-install-dismissed Mengingat bahwa ajakan pasang aplikasi sudah ditutup

Keamanan

  • HTTPS, Koneksi terenkripsi untuk semua halaman
  • Security Headers, CSP, X-Frame-Options, dan perlindungan lainnya
  • No External Data Transmission, File kamu tidak pernah meninggalkan browser
  • Regular Updates, Library dan dependensi selalu diupdate

Pertanyaan?

Kamu juga bisa langsung cek source code untuk memverifikasi semua klaim privasi di atas.
